Códigos de avería OBD2: qué significa cada uno

Cuando se enciende el testigo de avería del motor, la centralita guarda un código que dice qué ha detectado. Se lee con una máquina de diagnosis o con un lector OBD2 de los que se conectan al móvil.

Cómo se lee un código (por ejemplo, P0420):

  • La letra indica el sistema: P motor y cambio, B carrocería (airbag, climatización…), C chasis (ABS, dirección) y U comunicación entre centralitas.
  • El primer número: 0 es un código genérico, igual en todas las marcas; 1 es propio de cada fabricante.
  • El resto identifica el fallo concreto.
